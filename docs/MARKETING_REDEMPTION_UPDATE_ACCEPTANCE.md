# 兑奖预约与默认奖池调整 · 2026-09-20

## 实际调整

- 兑奖预约设置用语、独立状态列，批量和单个新增时段入口归入兑奖时段模块；复用现有Semi表格/抽屉/表单，未新增样式或组件库。
- 操作按对象归位，顶部只保留活动状态操作。
- 未单独配置的场次继承活动默认概率并使用未分配库存；有显式配置时整套覆盖，停用/未加入的奖品不回退。
- 首次从继承改为显式配置可填写分配数量，仍保护已中奖下限和其他场次保留数量；后续运行中数量继续通过调整动作维护。
- 独立、幂等追加200条预约/200条抽奖示意活动，三种指定奖品；原活动、历史快照、销售和会员数据保持不变。
