- Date: 2026-09-16
- Targets: local Vite runtime at `http://127.0.0.1:4173` and deployed HTTPS runtime at `https://gridworks.cn/mockup/kivisensecrm`

- Failed requests: 0
- Document horizontal overflow: 0 across captured viewports

## Automated functional coverage

The browser harness at `qa/prototype-browser-qa.mjs` resets the Demo dataset, captures both normal console failures and handled window errors such as `ResizeObserver` loops, then verifies:

1. HQ dashboard, distributor filtering, and topbar Demo User alignment containment.
2. Dashboard, Leads, Deals, Contacts, Organizations, Group Customers, Brand Members, Brand Purchase Intents, Products, Tasks, Distributors, Users, and Settings route entry.
3. `customer → user + user_profile → user_purchase_intent` browsing path.
4. Independent member-profile and purchase-intent `has_watch` mutations, with no cross-record overwrite.
5. Independent member reset and Sales LocalStorage byte-for-byte preservation.
6. Brand filtering, nullable purchase-intent links, and HQ-only member workspace access.
7. Lead creation and navigation to the shared detail workspace.
8. Qualified Lead conversion to a persisted Deal.
9. Deal Product and Add-on updates.
10. Mock email send, internal comment, call log, task creation/completion, note creation, and attachment upload.
11. Activity linkage for comments and completed tasks.
12. LocalStorage state after a full page reload.
13. Mark Won and native Kanban drag-to-stage behavior.
14. Contact notes and attachments.
15. HQ Product editing/Add-on management and distributor read-only behavior.
16. Distributor user navigation and record-scope isolation.

## Visual coverage

Final evidence contains 31 screenshots and 26 passing browser checkpoints:

- Dashboard, Leads, Deals, Group Customers, Brand Members, and Brand Purchase Intents at 1024×768.

The generated index, dimensions, hashes, and machine-readable results are written to `artifacts/prototype-qa/00-index.md` and `artifacts/prototype-qa/results.json`. The artifact directory is intentionally ignored because it is regenerated by the harness.

## Re-run

Start the app with `npm run dev`, then run:

```bash
npm run qa:browser
```
