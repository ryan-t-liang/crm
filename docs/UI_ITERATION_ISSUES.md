- 07-03-29概览回归：Los Angeles跨午夜后，原销售seed的当天09:20晚于查看时刻；页面标“未来记录（未纳入）”且新增Lead=7，而脚本只查日期下限得到8。补齐脚本与页面同一个固定查看时刻/日期上限，核对被排除的完整来源ID；保留FAIL截图，不改Dashboard生产查询、种子或测试业务断言。
- 07-08-21草稿弹窗回归：Semi的className落在只有fixed子元素的零尺寸外层；对外层使用:visible会超时，截图实际已打开Modal。根据安装版本ModalContent结构改定位其可见semi-modal子元素，继续断言body高度/overflow和取消动作，不删该检查。

## 测试脚本问题与不确定记录修正

- 早期分销商 /品牌选项名与实际DOM不一致，或未等待React/Semi行过渡结束，旧行count暂未变；改稳定定位与等待detached，不改业务结果。

- 新增审计检查最初未翻页，CLAIM在第2页，不能据此声称缺日志；改展示为最新优先并核对已保存记录。04-16-35 /04-19-11运行保留FAIL，最终PASS。
- 一次代码修正构建未过时启动的浏览器读到旧产物，不算最新源码通过；已重新完成类型/构建并跑三套最终QA，指纹记录在验收文档。
- 开发HMR期间的React同步卸载警告运行保留FAIL；最终稳定构建预览Console0。未屏蔽该错误或弱化断言。
