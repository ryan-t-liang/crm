# 数据概览 V1 指标口径

基线：2026-09-17；纯前端，Kivisense 销售演示与 Sowind 会员演示是两套企业数据。仅并列展示，不合并客户、线索、转化或企业总量。业务动作、两个 Store 和原 LocalStorage 键不变。

## 查询、日期与范围

共享实现：`frontend-react/src/features/dashboard/dashboard-model.ts`。顺序固定为授权 → 独立业务筛选 → 同一查看时刻的统计 / 明细。HQ 可查看全部销售与 GP/UN；分销商经理 / 销售沿用本人分销商范围，无会员权限。本轮不新增品牌角色；查询层测试额外验证单品牌权限与无集团权限，不代表 UI 已新增这些账号。

- `#dashboard` = 业务总览；`#dashboard/sales` = 销售概览；`#dashboard/members` = 会员运营概览。只有一个主导航入口，三个二级 Tab。
- 销售分销商与会员品牌筛选互不影响。日期只影响创建期指标，不影响当前存量。Tab 内切换与关闭抽屉保留选择；整页重载恢复默认筛选，不修改业务数据。
- 企业时区固定 Asia/Shanghai（UTC+08），与浏览器时区无关。无偏移 SQL DATETIME 按此时区只读解释；带偏移 ISO 保留实际时刻。这是本原型的明确配置，不声称真实 Sowind 服务器已使用相同时区。
- 默认最近30个自然日含今天；7天同理。今天从00:00，本月/季度从真实自然月/季度首日开始。
- 区间 `[start,endExclusive)`；自定义结束日含整天。所有创建期查询再要求 `created <= snapshot.now`，未来记录排除；已知未来创建的记录也不进入当前存量。缺创建时间的当前记录保留当前口径，并单列日期覆盖问题。自定义缺端、倒置、完全未来显示校验，禁止静默回退。
- 同一次页面计算使用固定查看时刻，卡片、图表、抽屉一致；刷新统计重取查看时刻。页面显示的数据更新时间指本次本地统计快照，不是后端同步时间。
- <=31天日桶；32–93天周桶（周一，首尾裁剪）；>93天月桶。桶连续不重叠，边界桶裁剪所选期，缺记录桶0，不推断增长率。

## 三种口径

| 标识 | 含义 | 创建期筛选 |
| --- | --- | --- |
| 本期新增 | 记录本期创建，不论当前状态 | 有 |
| 当前存量 | 截至固定查看时刻的当前可见记录 / 待处理记录 | 无 |
| 本期创建，截至当前 | 先选本期创建同一批记录，再看其当前结果 | 有；不是期间状态事件 |

没有 `closedAt` 不显示本期实际成交/输单/成交胜率；没有状态历史不推算曾经 Qualified、阶段时长、连续漏斗或过去的在途存量。`expectedClose`、`lastActivityAt`、`updated_at` 不替代成交日期。

## 销售指标（来源为销售 Store）

全部指标先受角色与所选分销商约束。当前归属不是历史归属归因。

| 名称 / 所在视图 | 公式及来源 | 口径 / 缺失处理 | 下钻 |
| --- | --- | --- | --- |
| 本期新增 Lead / 总览、销售 | count(Lead.createdAt 在所选期且不未来)，包括所有状态 | 本期新增；未知时间排除、覆盖说明 | 同一批 Lead |
| 本期新增 Deal / 总览、销售 | count(Deal.createdAt 在所选期且不未来)，所有阶段 | 本期新增；未知时间排除、覆盖说明 | 同一批 Deal |
| 新增 Lead 转 Deal 比例 / 销售 | 已确认转换的本期 Lead / 本期全部 Lead | 本期创建，截至当前；分母0为— | 同时显示分子 Lead 与分母 Lead |
| 转换数据待核验 / 销售 | 本期 Lead 状态与关联冲突 | 只读、不修复；不可见目标不泄露 | 冲突 Lead 自身，不输出隐藏目标 ID |
| 当前进行中 Deal / 总览、销售 | 当前阶段 DISCOVERY / SOLUTION / QUOTATION / NEGOTIATION | 当前存量，全部创建日期 | 相同范围全部开放 Deal |
| 当前未知 Deal 阶段 / 销售 | 阶段不在真实六阶段集合 | 当前待核验，不算进行中 | 当前未知阶段 Deal |
| 当前逾期销售任务 / 总览、销售 | status=OPEN 且 dueAt < snapshot.now | 当前存量，无创建期限制；非法到期值不判断逾期 | 相同范围逾期任务 |
| 新增趋势 / 销售 | 同一创建期 Lead、Deal 分别按共享桶统计 | 日/周/月，互非转化分母分子 | 图上点打开同桶两类分别标注的记录；逐桶表格打开对应序列记录 |
| 本期 Lead 当前状态 / 销售 | NEW / CONTACTED / NURTURING / QUALIFIED / CONVERTED / UNQUALIFIED / 未知 | 同批互斥，合计=新增Lead；比例分母为同批Lead | 分类数/条形为该类；占比同时显示分类与全批 |
| 当前 Deal 阶段 / 销售 | 当前进行中 Deal 四开放阶段 | 合计=当前进行中KPI，无创建期 | 分类与对应当前记录 |
| 本期 Deal 当前结果 / 销售 | 本期Deal互斥分进行中 / WON / LOST / 未知 | 同批合计=新增Deal | 分类与对应同批记录 |
| 已结案记录胜率 / 销售 | 本期创建的当前WON / (同批当前WON+LOST) | 本期创建，截至当前已结案；分母0为— | 分子WON、分母WON+LOST |
| 分销商分析 / 销售次级区 | 当前distributorId分组：本期Lead、本期Deal、该批当前WON/LOST | 创建期与当前结果分列，无渠道转化率 | 每格同组、同批、同结果记录 |
| 销售产品分析 / 销售次级区 | 当前productId分组：本期Deal及其中当前开放/WON/LOST | 当前产品归属，非历史归因；产品列不混腕表SKU | 每格相同产品Deal |
| 产品 Add-on / 销售次级区 | 按productId+capabilityId分组本期Deal及其中当前WON | 同名能力不跨产品合并；一Deal可有多个能力，不能跨行求业务总量 | 每格同产品、能力、创建期、结果的Deal |

确认转换同时要求：Lead.status=CONVERTED；convertedDealId 指向授权且符合当前分销商范围的唯一 Deal；Deal.sourceLeadId **必须**等于 Lead.id，不再把缺少反向来源的旧关联计为成功；归属分销商一致；授权 Lead 集合没有重复 convertedDealId 或重复 Lead.id；授权 Deal 集合没有重复 Deal.id，且唯一反向 sourceLeadId 就是该 Deal。一个 Lead 最多一次。关系冲突检查使用完整授权集合，不因日期或分销商的业务筛选漏掉可见的冲突。无效引用只标“待核验”，不泄露隐藏目标；不修复种子中的真实冲突。

### Core Integrity V1：共享指标与 Distributor Performance

`features/shared/sales-metrics.ts` 提供 `confirmedLeadConversion`、`confirmedConversions`、`dealOutcome`、`winRate`、`ratio`、`authorizedSales`。Dashboard 与 Distributor Performance 使用同一组函数，不复制转换或胜率公式。只识别四个明确的开放阶段；未知阶段不计进行中。

Distributor Performance 明确标记为“当前存量，截至当前”，不是 Dashboard 的“本期创建，截至当前”创建 cohort。当前 Lead 转 Deal = 当前已确认转化 Lead / 当前全部 Lead；当前已结案 Deal Win Rate = 当前 WON / (当前 WON + 当前 LOST)。分母为零统一显示 `—`，未结案 Deal 不进入胜率分母。当前列表和概况使用相同存量记录；已知未来创建记录排除，缺失日期保持只读当前口径，不补为今天。先做实际 actor 权限过滤，后做 distributor 归属过滤。

相同授权、时间范围和记录总体下，两页转换确认结果和胜率相同；不同时间总体不会伪称相同指标。新增共享回归覆盖双向缺失、重复前向/反向链接、跨范围冲突、零分母、未来创建与权限范围。

旧 Lead.productInterest 只有名称数组，缺乏可靠产品+能力关联，因此不编造跨产品 Add-on 兴趣数量；保留原 Lead 字段和展示。

## 会员指标（来源为会员 Store / 四张 Sowind 表）

只有授权品牌记录进入查询，品牌筛选不是权限。资料与意向快照互不覆盖；购买意向从不加入 Sales Lead/Deal。

| 名称 / 所在视图 | 公式及 SQL 字段 | 口径 / 缺失处理 | 下钻 |
| --- | --- | --- | --- |
| 集团客户记录数 / 会员 | 授权 customer.id 去重 | 当前存量，仅完整集团权限；不与品牌档案相加 | 去重 customer 行，不是user行 |
| 本品牌关联集团客户数 / 单品牌会员 | 当前该品牌有效user.customer_id与可见customer匹配去重 | 当前存量；NULL与失效引用另列 | 去重后的customer |
| 品牌档案数 / 会员 | user.is_deleted严格等于0 | 当前档案，非活跃会员/去重人数；缺删除状态排除单列 | 有效user |
| 当前购买意向数 / 会员 | 授权 user_purchase_intent 记录 | 当前存量，与销售独立 | 相同品牌意向 |
| 新增品牌档案 / 总览、会员 | 有效user.created_at在期且不未来 | 本期创建、当前未删除，非历史注册事件量 | 同一批有效user |
| 新增购买意向 / 总览、会员 | user_purchase_intent.created_at在期且不未来 | 本期新增，所有关联/同步状态 | 同一批意向 |
| 当前未关联会员意向 / 总览、会员 | user_purchase_intent.user_id严格等于NULL | 当前存量，允许的状态，中性待核查 | 同品牌NULL意向 |
| 当前关联待核验意向 / 会员 | 非NULL引用找不到有效、可见、同品牌user | 当前存量；不补关联/会员 | 当前无效引用意向，不输出隐藏目标ID |
| 当前同步异常 / 总览、会员 | hq_sync_status=0 且 trim(error)非空 | 当前存量，与普通未同步不同 | 同品牌异常意向、原错误内容 |
| 当前HQ同步状态 / 会员 | 0无错/0有错/1无错/1有错，未知另列 | 未同步/异常/已同步/状态与错误不一致；hq_ref不参与推断 | 各类当前意向；占比带全分类分母 |
| 品牌对比 / 会员 | 各授权brand的当前user/新增user/新增intent/当前NULLintent/当前异常 | 各列明确当前/本期；无权限不出另一品牌行或交集 | 原格相同品牌、日期、条件记录 |
| 集团品牌关系 / 会员 | 有效user.customer_id+brand，对customer.id去重分类GP-only/UN-only/both/none | 仅完整集团跨品牌授权且品牌ALL；前三类=至少一个已确认有效关联集团；none单列。占比分母为图中全部customer（含none） | 分类后去重customer；占比提供分子分母 |
| 未关联集团 / 会员覆盖说明 | 有效user.customer_id=NULL | 当前存量，不补建集团 | 相同user |
| 集团关联待核验 / 会员覆盖说明 | 有效user.customer_id非空但无可见customer | 当前存量，不按电话/UnionID合并 | user自身，不输出隐藏集团ID |
| 新增会员趋势 / 会员 | 有效user及intent的同期created_at分别分桶 | 相同轴，无注册到购买因果含义 | 图上点打开同桶两类分别标注的记录；逐桶表格打开对应序列记录 |
| 本期意向关联分布 / 会员 | 有效同品牌授权user / user_id=NULL / 关联不可用 | 同一批互斥、合计=新增意向；不是成交率 | 类别数/条形对应意向，比例带全批分母 |
| 意向商品分布 / 会员下方 | brand+product_sku；缺SKU用brand+model；都缺列未填写 | 同期intent，每条一次；未知原码字典待配置 | 对应品牌+SKU/型号/未填的同期意向 |

字段、类型、可空性、旧别名及原型扩展的逐项映射见 `SOWIND_MEMBER_FIELD_MAPPING.md`。HQ仅展示，未接接口或重试；未新增同步后端枚举。

## 未知、空与无权限

1. 无记录：0；有记录但全缺可用日期：暂不可统计，不伪装为0。存在已知日期但所选期为0：只说明已知日期内0，并列可点击待补数量。
2. 缺日期不进入卡片/趋势，非法日期同样待补；未来日期单列未纳入。品牌原记录日期覆盖包含删除状态待补记录，以免排除后遗忘待补时间。
3. user.is_deleted未知保留原数据、不猜0或1；全未知时有效档案及其新增显示暂不可统计，其他情况下显示已确认有效子集并提示排除数量。
4. 无权限：对应业务指标/明细不可见，不显示0或隐藏品牌数量。当前角色没有会员权限时直接会员概览URL只有拒绝提示；销售详情URL也受分销商只读范围检查。
5. 缺profile或关联不自动补建。NULL保留，不统一替换空字符串；原始枚举不统一布尔化。
6. Member LocalStorage 恢复异常时，会员摘要 / 会员概览显示“暂不可统计”及保留原始数据的恢复提示，不把空的恢复占位数据显示为零。业务总览的销售指标仍正常展示，会员覆盖和关注项暂停；只允许管理员确认恢复。Sales 恢复异常由应用恢复界面拦截，避免输出演示数据统计。

## 明细承接

本轮不扩展业务列表过滤契约，统一只读 Semi SideSheet，直接使用原指标记录数组。显示数据来源、授权范围、分销商/品牌、创建日期或“不随日期筛选变化”、分类定义、固定查看时刻；分页只分展示不改总量。比例显示分子与分母两组，集团显示去重客户；零记录显示明确空状态。关闭即返回原概览，筛选保持。权限、数据或查询改变会清掉旧抽屉。

## 缺少业务来源而未实现

本期实际成交数 / 真实成交事件胜率、历史连续转化漏斗、曾经Qualified、阶段停留天数、过去在途快照、同比环比、营销效果/ROI、活跃会员/复购/付费会员、等待跟进意向、会员完整率、Add-on跨产品兴趣归因。以上均未显示为0，不新增金额或后端字段迁就概览。
