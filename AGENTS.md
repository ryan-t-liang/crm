# Kivisense CRM repository instructions

Before changing CRM domain behavior, data models, migrations, RBAC, analytics, import/export, or frontend information architecture, read and follow [`docs/kivisense-crm-maintainer.md`](docs/kivisense-crm-maintainer.md).

The maintainer guide is mandatory for every file in this repository. More specific `AGENTS.md` files may add constraints but must not weaken its domain boundaries, data-preservation rules, or verification gates.
