# External Interaction References

This file is non-normative. It does not define Kivisense colors, typography, spacing, density, Cards, tables, navigation or component appearance.

Use it only when an external product is explicitly requested or the repository has no suitable interaction precedent. Translate the useful interaction into existing Kivisense components and visual language.

| Product | Interaction idea that may be considered |
|---|---|
| Plane | quick creation, compact action hierarchy, object-focused navigation |
| Frappe CRM | create the core record first, continue work on the record page |
| Twenty | list-to-record navigation and optional quick inspection |
| Linear | concise command and keyboard interaction patterns |
| Stripe | progressive disclosure for complex operational information |
| Shopify Admin | object-centered administration and contextual actions |
| HubSpot | CRM record relationships and activity organization |
| Salesforce | dense enterprise information architecture and permission-aware workflows |

These are prompts for analysis, not instructions to clone a product. Avoid statements such as “make it look like Plane” or “use Stripe-style cards.”

Do not copy third-party source by default. If source reuse is ever requested, review the exact file, package and current license separately before implementation.
